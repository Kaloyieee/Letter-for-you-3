# One Year of Us ♡

A romantic, responsive anniversary website made with **HTML, CSS, and JavaScript**.

## Features
- Soft blush, cream, and rose aesthetic
- Anniversary letter with your message
- Responsive layout for phones and desktops
- Small interactive surprise message
- Music player for your anniversary song

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. To enable the music player, place a legally obtained MP3 you have permission to use at `assets/our-song.mp3`.

## Music note
The player is prepared for **“Last Night on Earth” by Green Day**, but this repository does not include the copyrighted recording. Add your own legally obtained audio file as `assets/our-song.mp3` if you have the right to use it. The player starts after the visitor presses play because modern browsers generally block autoplay with sound. A click-to-play button is more reliable and respectful for visitors.

## Publish with GitHub Pages
1. Create a public repository on GitHub (for example, `one-year-of-us`).
2. Upload `index.html`, `style.css`, `script.js`, this `README.md`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site. The public URL will appear in the Pages section.

## Personalize it
- Edit the letter and headings in `index.html`.
- Change colors and typography in `style.css`.
- Replace `assets/our-song.mp3` with your own permitted audio file.
- You can add your own photos in an `assets` folder and place them in the HTML.
